# Inventory & Supply Chain Management Analysis

## Project Overview

This project analyzes inventory, warehouse, transportation, order, and supply chain performance using Power BI.

The objective is to identify trends, operational inefficiencies, inventory risks, transportation cost patterns, and warehouse utilization to support data-driven supply chain decision-making.

The dataset contains 1,200 supply chain records covering multiple regions, product categories, suppliers, warehouses, and order statuses.

---

## Business Objectives

- Monitor warehouse utilization and inventory efficiency
- Analyze inventory levels across regions and product categories
- Track units sold over time
- Analyze transportation costs by region and product category
- Monitor supplier and operational performance
- Analyze order and backorder status
- Evaluate lead time across product categories
- Identify inventory and supply chain trends
- Support operational planning and decision-making

---

## Dataset

The dataset contains 1,200 records and 15 fields.

### Key Columns

| Column | Description |
|---|---|
| Date | Date of the supply chain transaction |
| Region | Geographic region |
| Category | Product category |
| Supplier | Supplier associated with the transaction |
| Warehouse | Warehouse associated with the transaction |
| Order Status | Fulfilled, Pending, or Canceled |
| Units Sold | Number of units sold |
| Inventory Level | Current inventory level |
| Transportation Cost | Transportation cost associated with the transaction |
| Order Accuracy | Indicates whether the order was processed accurately |
| Lead Time (Days) | Number of days required for delivery |
| Backorder | Indicates whether the order was backordered |
| Cost of Goods Sold (COGS) | Cost associated with goods sold |
| Average Inventory | Average inventory level |
| Warehouse Capacity | Maximum warehouse capacity |

## Dashboard Analysis

### 1. Warehouse Utilization

Analyzes warehouse inventory levels relative to available warehouse capacity.

This helps identify warehouses with higher utilization and potential capacity constraints.

### 2. Transportation Cost Analysis

Analyzes transportation costs across:

- Regions
- Product categories

This helps identify cost patterns and areas for transportation cost optimization.

### 3. Sales & Volume Trend

Tracks units sold over time to understand changes in demand and sales volume.

### 4. Lead Time Analysis

Analyzes average lead time across product categories to identify differences in supply chain performance.

### 5. Order Status Analysis

Analyzes order fulfillment status across:

- Fulfilled
- Pending
- Canceled

This provides visibility into order processing and potential operational issues.

### 6. Inventory Analysis

Analyzes inventory levels by:

- Region
- Product category

This helps identify inventory concentration and potential supply-demand imbalances.
